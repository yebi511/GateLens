# ADR 0005：将模型路由建模为可联邦的多跳拓扑

- 状态：Accepted
- 日期：2026-07-24

## 背景

生产环境常将 Higress 入口网关、Istio 入口网关和推理服务放在不同命名空间或不同 Kubernetes 集群。将所有上游都假设为当前集群的 Service/Endpoint，会遗漏授权检查并虚构远端路径。

## 决策

领域模型分别记录 Gateway 工作负载位置、配置对象位置、服务位置和集群位置。跨命名空间后端引用保留 `ReferenceGrant`/状态证据；跨集群转发使用显式 `TransitHop` 和 `ClusterLink`，由 `FederatedSnapshot` 固定所用的各集群快照。

MVP 支持跨命名空间校验和远端边界展示。只有相关远端集群接入后，才解释其 Istio/Higress 配置；没有远端数据时不推断内部路径。

## 后果

图与解释结果更准确，也会增加多集群身份、快照一致性和连接登记的实现工作。跨集群“实际已到达”的结论仍依赖阶段 2 的 Trace、日志或指标证据。
