# ADR 0001：以规范化领域模型隔离网关差异

- 状态：Accepted
- 日期：2026-07-24

## 背景

Gateway API 提供公共抽象，但 Envoy、Istio、Higress 及推理扩展在 CRD、状态字段和运行时行为上存在差异。若 UI 和查询 API 直接依赖一个实现，项目无法扩展，也无法清楚表达差异。

## 决策

核心使用 `TopologySnapshot`、节点、边、策略、后端候选和证据的规范化模型。每个实现由版本化适配器转换，并保留 `ResourceRef` 回链原始对象。

## 后果

核心查询和 UI 可复用；新增实现需要适配器和兼容性测试。模型不能抹平语义差异，适配器必须声明不支持或无法确定的行为。
