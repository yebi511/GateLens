# ADR 0004：前端 MVP 聚焦静态配置解释

- 状态：Accepted
- 日期：2026-07-24

## 背景

GateLens 最终需要支持配置、控制面状态和数据面证据。但日志、追踪和指标连接器需要额外的部署、权限、字段约定与关联质量验证；若把它们作为前端首版前提，会阻塞最核心的配置理解任务。

## 决策

前端 MVP 只交付有效拓扑、请求模拟、配置健康和资源核验四个视图。所有请求模拟绑定不可变快照，并明确标注为 `Inferred`。真实请求时间线与“配置推断/实际观测差异”在证据连接器成熟后进入阶段 2。

## 后果

首版可以在只读 Kubernetes 数据源下独立交付，功能边界清楚。用户仍需到现有可观测系统核实实际请求，直到阶段 2 完成。
